# Acinetobacter baumannii Draft Genome Sequences

This repository contains draft whole-genome sequences of *Acinetobacter baumannii* isolates.

## Background

The isolates were received by our laboratory (Barr Lab, Monash University, Australia) through various collaborations. We performed whole-genome sequencing (WGS) on them to support studies across different areas of biology.

We do not know whether these sequences have already been deposited in public databases such as NCBI. To avoid duplicating data that may already be in NCBI, we are making the sequences available only through this repository.

## Purpose

 These sequences are shared for research use only, to support work on A. baumannii genomics.
